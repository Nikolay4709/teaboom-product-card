# Карточка товара Teaboom.ru: «Ананасовый улун»

Тестовое задание на позицию HTML-верстальщика. Верхняя часть карточки товара интернет-магазина Teaboom.ru.

## Демо

- Страница: https://USERNAME.github.io/teaboom-product-card/
- Репозиторий: https://github.com/USERNAME/teaboom-product-card

## Стек

HTML5, SCSS (БЭМ), нативный JavaScript (ES-модули). Vite используется только как сборщик: компилирует SCSS, отдаёт dev-сервер и собирает статику для GitHub Pages. Фреймворков и UI-библиотек нет.

Зависимости:

- vite, sass: сборка и стили;
- @fontsource-variable/open-sans: шрифт сайта Teaboom (Open Sans) лежит локально, а не на Google Fonts, поэтому страница не зависит от доступности внешнего CDN;
- stylelint, prettier: линтинг и форматирование;
- vitest, @playwright/test: unit- и e2e-тесты.

## Как запустить

```bash
pnpm i
pnpm dev        # dev-сервер на http://localhost:5173
pnpm build      # сборка в dist/
pnpm preview    # просмотр сборки
pnpm lint       # stylelint + prettier
pnpm test       # unit-тесты (Vitest)
pnpm test:e2e   # e2e-тесты (Playwright, локально использует установленный Google Chrome)
```

## Структура

```
index.html                 разметка карточки
public/images/             фото товара в WebP (480 и 800 px)
src/styles/
  _tokens.scss             цвета, радиусы, брейкпоинты и миксин from()
  _base.scss               сброс, база, контейнер страницы
  _product.scss            блок product: сетка и элементы карточки
  _weights.scss            блок weights: выбор фасовки
  _button.scss             блок button
  _specs.scss              блок specs: характеристики заваривания
src/scripts/
  price.js                 форматирование цены и расчёт скидки
  product-card.js          переключение фасовки и «В корзину»
e2e/                       e2e-тесты и скрипт скриншотов
```

## Что сделано

- Все элементы из ТЗ: фото, название, категория (ссылка на раздел сайта), фасовки, артикул, актуальная и старая цена, кнопка «В корзину», короткое описание.
- При смене фасовки меняются артикул, цена, старая цена, бейдж скидки и выбранное состояние. Данные каждой фасовки хранятся в data-атрибутах радиокнопки, JS только читает их и обновляет текст.
- Фасовки сделаны на нативных радиокнопках внутри fieldset: работают с клавиатуры (Tab, стрелки), читаются скринридером как группа «Фасовка».
- Кнопка «В корзину»: обычное состояние, hover, active, focus-visible и disabled. По клику появляется сообщение «Добавлено в корзину» в role="status", его озвучивает скринридер.
- Без JS страница остаётся рабочей: в разметке уже стоят данные первой фасовки.
- Адаптив по Mobile First:
  - до 768 px: одна колонка, кнопка на всю ширину, на экранах уже 360 px фасовки выстраиваются сеткой 2×2;
  - 768 px: фото и блок покупки в две колонки, описание на всю ширину под ними;
  - от 1024 px: фото закреплено слева (sticky), покупка и описание справа.
- Стилистика Teaboom: Open Sans, фирменный жёлтый #f5d730, кремовый фон блока покупки, красная цена.
- Проверено на 320, 375, 768, 1024 и 1440 px: горизонтального скролла нет, в консоли нет ошибок.

## Допущения

- Цены показаны в русском формате, как в ТЗ («326,40 ₽», «1 432 ₽»), а не как на сайте («1432.00 ₽»).
- Шапку, меню, хлебные крошки и боковое меню категорий не верстал: в ТЗ нужна только верхняя часть карточки.
- В качестве категории взят раздел из хлебных крошек сайта: «Китайский светлый ароматизированный улун».
- Короткое описание собрано из текста товара на сайте, к нему добавлены 4 ключевые характеристики заваривания.
- Наличие («В наличии») одинаковое для всех фасовок, как на сайте.
